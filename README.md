# MASS

> MASS is a service-based company offering **AI services, web development, and app development**. This repository contains the company website.

## 🌐 Overview

A modern, responsive website built to present MASS's services and convert visitors into clients, with clean structure and a focus on performance and UX.

## ✨ Features

- Fully responsive, mobile-first layout
- Service sections (AI, Web Development, App Development)
- Clean, component-based structure
- Optimized for speed and SEO

## 🛠️ Tech Stack

- **TypeScript**
- **CSS**
- Modern component-based front-end architecture

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/arundhatibiswas/MASS.git
cd MASS

# Install dependencies
npm install

# Run the development server
npm run dev
```

> Adjust the commands above to match the project's actual package scripts.
